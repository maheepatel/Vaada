# Vaada launch film

Standalone Remotion project. Kept out of the Next app's dependency tree on
purpose: Remotion pins its own React and bundler, and sharing `node_modules`
with Next 16 causes version conflicts that are tedious to unpick.

```bash
cd video
npm install
npm run studio        # hot-reload preview
npm run render        # 16:9 -> out/vaada-launch.mp4
npm run render-vertical   # 9:16 -> out/vaada-launch-vertical.mp4
```

## The edit

Four acts across 30 seconds at 30fps. Scene boundaries live in one place,
`src/theme.ts`, so the whole film can be retimed without touching a scene.

| Act | Frames | Beat |
| --- | --- | --- |
| I — the wound | 0–330 | Road, classroom, protest, then a wordless monsoon |
| II — the turn | 330–390 | "Until someone writes it down." |
| III — the clock | 390–750 | Product, the 48-hour promise, the 21 undated |
| IV — the answer | 750–900 | Proof gate, endcard |

Act I is slow and almost wordless on purpose. A product film wants to reach the
product fast; here the product only means anything after the viewer has sat in
the problem for eleven seconds, so the screenshot arrives as relief rather than
as a feature list.

The longest hold in the film is the 21-undated beat. It is the one thing only
this register can show, and the skill's rule is that the differentiating beat
gets the screen time.

## Rules this film follows

**Every product string is real.** "Make the commuting road usable", "in the next
48 hours", "4d over", "Add a photo or a link before submitting.", "Evidence:
Photo or scan" — all copy that exists in the app. Inventing UI labels is the
fastest way to make a launch film feel fake, and on an accountability register
it would be the exact thing the product exists to refuse.

**No photorealistic footage.** The artwork is screenprint illustration with no
faces and no identifiable people. A register whose entire claim is "every entry
traces to a published source" cannot open on synthetic footage of real-looking
Indians and expect to be believed — it hands critics the stick.

**Silent.** 85% of feed views are muted, so nothing depends on audio. Drop a
licensed track into `public/audio/` and add an `<Audio>` tag in
`VaadaLaunch.tsx` if you want score; the cut points are already on musical
boundaries at 3s intervals.
